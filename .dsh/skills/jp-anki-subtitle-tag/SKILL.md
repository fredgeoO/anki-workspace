# 日语 Anki · 字幕/文字生词打标（`复习::<名称>`）

本技能覆盖**一件事**：把一段字幕或文字里、你还**没学过**、**也还没被复习标过**的词，从三个词汇卡组里挑出来，打上 `复习::<名称>` 标签。方便在 Anki 浏览器里一次性复习。

> 标签 2026-10-23 由 `字幕复习` 更名为 `复习`；历史 `字幕复习::*` 已全部迁移，现在只认 `复习`。

## 一、边界（不可越线）

| 允许 | 不允许 |
|---|---|
| 给词笔记加 **一个** 标签 `复习::<名称>`（**该词还没有任何复习标签时**） | 写 `due` / `ivl` / `factor` / `type` / `queue` / `reps` / `lapses` |
| 回退时摘掉这**一个**标签 | 改任何字段（`Word` / `Sentence` / `AINote` …）、改 deck、加日期标签 |
| 只读三个词汇卡组 + 只读字幕/文字；查「是否已标过」时只读 `0-词汇` 下其它子牌组（如 `4-复习`）的标签 | 写 `3-专有词汇`、动其它牌组、改字段 |
| 写 `data/subtitle_review/<输入名>/` 下的提取产物与 `tags_applied.json` | 顺手排期、顺手建卡、顺手配音 |

- 「没学过」的判定与 `subtitle_new_words.py` 完全一致：该词**所有**卡都是新卡（`type == 0`）。
- **一个词只挂一个复习标签**：词（它的任意一张笔记）已带 `复习` 或 `复习::*` → 不再标，
  也不管那个标签来自哪一集。重复出现在新字幕里的词不会被第二次打标。
- 排期（改 `due`、把新卡设成明天到期）不是本技能的事：原排期工具 `wordlist_due.py` / `subtitle_review.py` 已于 2026-10-23 删除；新卡排期走 `jp-anki-activate`。

## 二、命令（先把两个变量设好）

```powershell
$WS = "<工作区根>"
$PY = "python"
$TAGTOOL = "$WS\code\tools\subtitle_tag.py"
```

> 开工前先过强制门禁：`& $PY "$WS\code\cli.py" doctor`（0 阻塞才动手）。

### 2.1 默认动作：直接真写

```powershell
& $PY $TAGTOOL "subtitles\Yani Neko\ヤニねこ.S01E01.ニャーがヤニねこにゃ.WEBRip.Netflix.ja_[cc].srt" --name ヤニねこ --commit
```

`--name` 只给来源名，**不要**自己拼 `复习::`（脚本拼）。

### 2.2 先看名单（不写库）

```powershell
& $PY $TAGTOOL "字幕.srt" --name ヤニねこ
```

词多、怕噪声（`ウンコ` 这类）时加过滤，再加 `--commit`：

```powershell
& $PY $TAGTOOL "字幕.srt" --name ヤニねこ --min-occ 2 --commit            # 至少出现 2 次
& $PY $TAGTOOL "字幕.srt" --name ヤニねこ --exclude "ウンコ,まつ" --commit  # 点名剔除
& $PY $TAGTOOL "字幕.srt" --name ヤニねこ --limit 30 --commit            # 只标前 30 个（按出现次数）
```

### 2.3 文字输入（不是字幕）

```powershell
& $PY $TAGTOOL "notes\青空文庫.txt" --name 青空文庫 --commit
Get-Content draft.txt -Encoding UTF8 | & $PY $TAGTOOL - --name 随笔 --commit
```

一行一句即可（`.txt` 的每行当一条台词）。前缀仍是 `复习::`，浏览器里 `tag:复习` 能一次看全所有来源。

### 2.4 回退（摘掉本标签）

```powershell
& $PY $TAGTOOL "字幕.srt" --revert --commit
```

回退依据是 `data/subtitle_review/<输入名>/tags_applied.json`（只含本次打过的 noteId + tag）；只摘这一个标签，别的 tag 不动。

## 三、输出怎么读

| 输出行 | 含义 | 正常值 |
|---|---|---|
| `✅ 可复习的新词 N 个（出现 M 次）` | 本集提取规模（含下面被「已带复习标签」跳过的） | 0 也算成功 |
| `⛔ 已学过 X 个 / 已挂起 Y 个` | 被排除的量 | 挂起数一般 0–2 |
| `标签：复习::<名称>` | 本次要打的标签 | 与 `--name` 对应 |
| `可标记 N 个词；已带复习标签 K 个；本次要打 T 个` | 幂等结果 | 复跑时 `T = 0` |
| `（已带复习标签，跳过）：…` | 词已带复习标签（本来源或别的来源；最多列 20 个） | 重复看过的词会出现在这里 |
| `⛔ … 已不是新卡（type=1/2/3）` | 两次运行之间被学过 | 罕见的正常情况 |
| `已打标签 T 个；回读校验通过` | 真写结果 | `T` 与预期一致、校验通过 |
| `无需变更。` | 没有要打的 | 复跑正确结果 |

## 四、机械规则（脚本已做，别在提示词里重算）

- **卡组来源**：`code/common/jp_decks.py` 的 `DECK_MINED` / `DECK_CORE6000` / `DECK_KAOKYU`。牌组改名只改 `jp_decks.py`；若脚本报 `牌组不存在或没有子牌组`，**停手问用户**，不要改脚本里的字符串。
- **同词多卡**：只标 `subtitle_new_words.py` 选定的那一张（卡组优先级 core6000/考级 > 素材生词）；但「是否已标过」按**整词**判：该词任一笔记带 `复习::*` 就整词跳过。
- **挂起的新词不标**（`queue == -1`）；**埋藏的新卡照标**（打 tag 不会解除埋藏）。
- **幂等**：同一个 `--name` 再跑，已带标签的跳过，输出 `无需变更`。
- **名称 → 标签**：`复习::` + 名称；名称里的 `::` 或 `/` 当层级分隔（`七大罪::第一季` → `复习::七大罪::第一季`），其余非法字符转 `_`。
- **搜索语法**：单集用 `tag:"复习::ヤニねこ"`（带引号）；全部用 `tag:复习`（会命中所有子标签）。
- 打完标签后 Anki 浏览器要**切走再切回或 F5** 才刷新（编辑器同理）。
- `--limit` 只截断「这次打标的词」，`words.json`/`report.md` 仍写全量。

## 五、失败处理

| 现象 | 动作 |
|---|---|
| `AnkiConnect 不可用 … 请先启动 Anki` | 让用户打开 Anki，重跑（脚本幂等） |
| `牌组不存在或没有子牌组：0-日本语学习::0-词汇::…` | `jp_decks.py` 与库里牌组名对不上。**问用户**改哪边，别自己猜 |
| `没有从字幕里解析出任何台词：…` | 输入路径写错 / stdin 是空的 / 字幕格式不认识；确认文件与编码后重跑 |
| `⚠ 本次没有新的可标记词；保留上一次的提取结果` | 这集已经全标过、或词都学完了。`tag:"复习::<名称>"` 查一下即可 |
| `回读校验失败：…` | 退出码 1。立刻 `--revert --commit` 回退，把那几个词名报给用户 |
| `找不到回退记录 …tags_applied.json` | 这张输入没在本工具里打过标签（或改了 `--out`）；别手工摘 tag，先确认来源 |

**不要**为了绕过上述问题去 `sqlite3` 直连库、改 `jp_decks.py`、或手工在 Anki 里批量加 tag——工作区只走 `code/common/anki_api.py`。

## 六、收工汇报（给用户）

1. 输入是什么（文件路径或「粘贴文字」）、标签名 `复习::<名称>`；
2. 打了几个、按卡组分布（素材生词 / 高频 6000 / 考级）；
3. 词表（按卡组列词，带出现次数更好）；
4. 跳过项：已学过多少、已带复习标签哪些、挂起哪些、`--exclude` 剔了哪些；
5. 回退命令（`--revert --commit` 那条原样给出）。

## 七、与其它技能的边界

- 新卡排期 → `jp-anki-activate`（`wordlist_due.py` / `subtitle_review.py` 已于 2026-10-23 删除）。
- 素材生词建卡 → `jp-anki-mine`；专有名词收集 → `jp-anki-proper-noun`；清理 → `jp-anki-triage`；生成 → `jp-anki-generate`；配音 → `jp-anki-audio`。
- 本技能**只加一个标签**，别的阶段要动卡请加载对应技能。
