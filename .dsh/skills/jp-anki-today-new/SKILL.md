# 日语 Anki · 今天学习生词（每日挑 N 个）

本技能覆盖**一件事**：每天给一段文字/字幕，挑出 **N 个今天最值得学、而且你还没学过**的词，打上 `今天学习生词` 标签；旧的同标签先摘掉，所以这个标签永远只代表「今天这一批」。

> 排序只看 `JitenAnimeRank`：数字越小 = 在动漫语料里出现频率越高 = 越优先。出现次数只是同排名时的次序，不是主判据。
>
> 本技能**只打标签**。标签不是排期：它不会把这 N 个词挪到新卡队首；要改学习顺序请另加载 `jp-anki-activate`。

## 一、边界（不可越线）

| 允许 | 不允许 |
|---|---|
| 加 / 摘 **一个** 标签 `今天学习生词` | 写 `due` / `ivl` / `factor` / `type` / `queue` / `reps` / `lapses` |
| 读三个词汇卡组、读全库 `tag:"今天学习生词"` | 改任何字段（`Word` / `JitenAnimeRank` / `AINote` …）、改 deck |
| 写 `data/daily_new/` 与 `output/daily/today_new_words.md` | 建卡、删卡、配音、动 `3-专有词汇` |
| 回退时恢复上一次运行前的标签集合 | 加日期标签、加 `::` 前缀、顺手排期 |

- **「没学过」口径**与 `subtitle_new_words` 完全一致：该词**所有**卡都是新卡（`type == 0`）。只要有一张卡在学习/复习/重学，就算学过，不进候选。
- **一个词只标一张代表卡**：core6000 / 考级 > 素材生词；新卡优先；埋藏的新卡也照标（打 tag 不解除埋藏）。
- **已带 `复习::*` 的词仍可入选**：今天学习集与字幕复习集互相独立。
- **没有 `JitenAnimeRank`（空 / `999999`）的词排最后**，只在有排名的词不足 N 时补位。
- **全量替换**：同一天换一段文字再跑，以最后一次结果为准；旧标签里今天没选中的会被摘掉，选中的保留（不重复写）。
- **0 个候选时不改库**：保留旧标签并退出码 2，先检查输入/是否全学完，不要默认清空。

## 二、命令（先把两个变量设好）

```powershell
$WS = "<工作区根>"
$PY = "python"
$PICK = "$WS\code\tools\today_new_words.py"
```

> 开工前先过强制门禁：`& $PY "$WS\code\cli.py" doctor`（0 阻塞才动手）。Anki 必须开着。

### 2.1 先看名单（演练，不写库）——默认动作

```powershell
& $PY $PICK "subtitles\ARIA The ANIMATION\Aria The Animation 03.jp.srt" --n 30
```

看三样：候选数、入选的前 30 个、旧标签会摘几个。名单里混进人名/语气词/太基础的词，先别 commit，报给用户决定。

### 2.2 真写

```powershell
& $PY $PICK "字幕.srt" --n 30 --commit
```

### 2.3 文字输入（不是字幕）

```powershell
& $PY $PICK "notes\青空文庫.txt" --commit
Get-Content draft.txt -Encoding UTF8 | & $PY $PICK - --commit
```

支持 `.srt` / `.vtt` / `.ass` / `.ssa` / `.txt`；`-` 从 stdin 读纯文本。

### 2.4 只清空这个标签（不选新词）

```powershell
& $PY $PICK --clear --commit
```

### 2.5 撤销上一次运行

```powershell
& $PY $PICK --revert --commit
```

`--revert` 依据 `data/daily_new/state.json` 里运行前的 noteId 集合恢复；只动 `今天学习生词` 一个标签。state 只保留最近一次运行，多次运行后只能回退到最后一次之前。

### 2.6 走统一入口（等价）

```powershell
& $PY "$WS\code\cli.py" today-new "字幕.srt" --n 30 --commit
```

## 三、输出怎么读

| 输出行 | 含义 | 正常值 |
|---|---|---|
| `候选：C 个（Anki 已有、所有卡都是新卡）` | 这段文字命中多少可学词 | 越多越好，0 说明全学完或输入没命中 |
| `现场复核后可用：M 个` | 扣掉刚被学过/删掉的卡 | M ≥ 入选数 |
| `旧标签：X 个；保留 K；摘除 R；新增 A` | 全量替换的差集 | 最终 = K + A = 入选 ≤ N |
| `今天要学的词…` | 名单：词 / 读音 / Jiten / 本段次数 / 牌组 / 首句 | 按 Jiten 升序 |
| `现场复核剔除` | 两次读取之间被学过的卡 | 一般 0 |
| `回读校验通过` | 写后重查标签集合 = 入选集合 | 必须是「通过」 |
| `没有可选的词：本次不改库…` | 候选 0，旧标签保留 | 检查输入或是否已学完 |

产物（commit 后写）：

- `output/daily/today_new_words.md` —— 给人看的稳定路径报告（每次 commit 覆盖）
- `data/daily_new/<日期>/picked.json` —— 机器可读：候选/入选/剔除/差集（`picked[]` 的顺序就是每日讲义的排序：Jiten 升序）
- `data/daily_new/state.json` —— 回退记录（运行前 / 运行后 noteId）

## 四、机械规则（脚本已做，别在提示词里重算）

- **排序键**：`JitenAnimeRank` 升序 → 无排名最后 → 同排名按本段出现次数降序 → 词形。
- **词的排名**取该词**所有笔记**里的最小值（同词在多个牌组时，不取被选中那张的单一字段）。
- **判定「学过」按整词**：任一卡 `type != 0` 即排除；不是只看被选中的那张。
- **写前差集**：旧集合与新集合比较，只摘 `旧 - 新`、只加 `新 - 旧`，交集不动（幂等，避免反复改 `mod`）。
- **上限**：`len(最终标签集合) == len(入选)`；脚本写后 `find_notes('tag:"今天学习生词"')` 回读校验。
- **同词只标一张代表卡**：`subtitle_new_words` 的 `_pick_entry` 已按「新卡优先 → core6000/考级 > 素材生词」选好。
- **回退记录**：commit 前先写 `state.json` 的 `before`，再动库；`--revert` 用它恢复。
- 打完标签后 Anki 浏览器要**切走再切回或 F5** 才刷新。

## 五、失败处理

| 现象 | 动作 |
|---|---|
| `AnkiConnect 不可用 … 请先启动 Anki` | 让用户打开 Anki，重跑（脚本幂等） |
| `牌组不存在或没有子牌组：0-日本语学习::0-词汇::…` | `jp_decks.py` 与库里牌组名对不上。**问用户**改哪边，不要自己猜 |
| `没有从字幕里解析出任何台词：…` | 路径写错 / stdin 为空 / 字幕格式不认识；确认文件与编码后重跑 |
| `没有可选的词：本次不改库` | 这段文字里没有「已有且未学」的词。别 commit，先问用户是否换输入或确实要 `--clear` |
| `回读校验失败：缺失/多出 …` | 退出码 1。先 `--revert --commit` 恢复，再把缺失/多出的 noteId 报给用户 |
| `找不到回退记录 …state.json` | 还没用本工具 commit 过（或 `data/daily_new` 被清理）；不要手工摘 tag，先确认来源 |
| 名单里出现人名/语气词/基础词 | 现有提取器已过滤人名（默认）/惯用句/词缀；仍混进来就**先给用户看**，不要自己改过滤规则或 `--commit` |

**不要**为了绕过上述问题去 `sqlite3` 直连库、改 `jp_decks.py`、或手工在 Anki 里批量加 tag——工作区只走 `code/common/anki_api.py`。

## 六、收工汇报（给用户）

1. 输入是什么（文件路径或「粘贴文字」）、`--n` 是多少、有没有 `--commit`；
2. 候选 / 入选 / 无排名补位各多少；
3. 今天的词表（按 Jiten 升序，带读音、排名、牌组、首句）；
4. 标签变化：旧标签几个、保留几个、摘除几个、新增几个，回读校验是否通过；
5. 回退命令：`python code\tools\today_new_words.py --revert --commit`；清空命令 `--clear --commit`。

## 七、与其它技能的边界

- 要把这 N 个词排到新卡队首（改 `due`）→ `jp-anki-activate`；本技能**不排期**。
- 字幕/文字的复习标签 `复习::*` → `jp-anki-subtitle-tag`；两者标签不同、可并存。
- 文字里出现、但 Anki 里没有的词 → 不在本技能范围（本技能只挑「已有新卡」）；挖词建卡 → `jp-anki-mine`。
- 每日讲义 → `jp-anki-daily-lesson`；弱项分析 → `jp-anki-daily-weak`；`JitenAnimeRank` 回填 → `jp-anki-jiten-rank`。
- 本技能**只加/摘一个标签**，别的阶段要动卡请加载对应技能。
