# 日语 Anki · 今天学习生词（每天按本作暴露挑 30 个词）

本技能覆盖**一件事**：给一集字幕或一整部作品的字幕目录，从**已有词库**里挑出 30 个
今天最值得学、而且你还没学过的词，给它们打上 `今天学习生词` 标签；旧的同标签先摘掉，
所以这个标签永远只代表「今天这一批」。

> **统计窗口 = 整部作品**：给一集字幕，脚本会自动把**同目录其它集**一起扫掉，用来算
> 「出现次数」和「跨了几集」。只给一集的话，`跨集数` 永远是 1，集数项等于没有。
>
> **排序是一个连续打分公式，纯代码**：没有模型判断，没有 AI 分，也没有分池门槛了。
>
> 本技能**只打标签**。标签不是排期：它不会把这 N 个词挪到新卡队首；要改学习顺序请另加载 `jp-anki-activate`。

## 一、边界（不可越线）

| 允许 | 不允许 |
|---|---|
| 加 / 摘 **一个** 标签 `今天学习生词` | 写 `due` / `ivl` / `factor` / `type` / `queue` / `reps` / `lapses` |
| 读三个词汇卡组、读全库 `tag:"今天学习生词"` | 改任何字段（`Word` / `JitenAnimeRank` / `AINote` …）、改 deck |
| 写 `data/daily_new/` 与 `output/daily/today_new_words.md` | 建卡、删卡、配音、动 `3-专有词汇` |
| 回退时恢复上一次运行前的标签集合 | 加日期标签、加 `::` 前缀、顺手排期 |

- **「没学过」按笔记判断**：同一词形下，已学的那张笔记排除，**别的未学笔记照选照标**。
  听辨卡和看字辨意卡服务不同功能，本来就该各有一张。
- **一个词打名下所有未学笔记**：名额按**词**算（30 个词），所以最终标签数可能多于 30。
- **JAR 门槛 1–30000**：无排名（空 / 0 / 999999）与 JAR >30000 的词不参与选择。
  超范围的**不建新卡**，只排除。
- **不去重**：复合词各自独立（`魔神` / `魔神族` 都算候选），同词多写法也不合并。
- **已带 `复习::*` 的词仍可入选**：今天学习集与字幕复习集互相独立。
- **全量替换**：同一天换材料再跑，以最后一次结果为准；旧标签里今天没选中的会被摘掉。
- **0 个候选时不改库**：保留旧标签并退出码 2，先检查输入/是否全学完，不要默认清空。

## 二、命令（先把两个变量设好）

```powershell
$WS = "<工作区根>"
$PY = "python"
$PICK = "$WS\code\tools\today_new_words.py"
```

> 开工前先过强制门禁：`& $PY "$WS\code\cli.py" doctor`（0 阻塞才动手）。Anki 必须开着。

### 2.1 先看名单（演练，不写库）——默认动作

```powershell
# 目录：整部作品一次扫完
& $PY $PICK "subtitles\Yani Neko"

# 给一集也行：自动扩到同目录整季
& $PY $PICK "subtitles\Yani Neko\ヤニねこ.S01E01.…srt"
```

看四样：窗口几集、分池（A/B/D/E）、入选的 30 个词、旧标签会摘几个。名单里混进
人名/语气词/太基础的词，先别 commit，报给用户决定。

### 2.2 真写

```powershell
& $PY $PICK "subtitles\Yani Neko" --n 30 --commit
```

### 2.3 纯文本输入（不扩展目录，集数按 1 算）

```powershell
& $PY $PICK "notes\青空文庫.txt" --commit
Get-Content draft.txt -Encoding UTF8 | & $PY $PICK - --commit
```

支持 `.srt` / `.vtt` / `.ass` / `.ssa` / `.txt`；`-` 从 stdin 读纯文本。
字幕**只扫同目录、不进子目录**（`anki/` 里的重复字幕不会被数两遍）。

### 2.4 只清空这个标签（不选新词）

```powershell
& $PY $PICK --clear --commit
```

### 2.5 撤销上一次运行

```powershell
& $PY $PICK --revert --commit
```

`--revert` 依据 `data/daily_new/state.json` 里运行前的 noteId 集合恢复；只动
`今天学习生词` 一个标签。state 只保留最近一次运行。

### 2.6 走统一入口（等价）

```powershell
& $PY "$WS\code\cli.py" today-new "subtitles\Yani Neko" --n 30 --commit
```

## 三、打分公式（对象是已有词的笔记）

```
S = ln(1+次数) + MU*ln(1+集数) + LAM*ln(30000/JAR)
```

等价乘积形式：`(1+次数) * (1+集数)^MU * (30000/JAR)^LAM`

| 参数 | 默认 | 作用 | 怎么调 |
|---|---|---|---|
| 次数项 | 权重固定 1 | 本作里出现越多分越高 | 不改（这是主信号） |
| `MU` | 0.3 | 跨集覆盖的加成 | `--mu 0` 完全不看跨集；`--mu 0.5` 更奖励多语境 |
| `LAM` | 0.3 | JAR（全球词频）加成 | `--lam 0.5` 更看重高频词；`--lam 0.8` 会把 おっ 顶到第 1 |

**参数是可换算的**：次数翻倍 = `ln2`，JAR 前移 k 倍 = `LAM*ln k`，所以
`k = 2**(1/LAM)`。默认 0.3 即「**次数翻一倍 ≈ JAR 排名前移 10 倍**」。

三条设计约束（别在提示词里重新发明）：

- **三项都取对数**：次数和排名都是重尾分布，线性相加会被 JAR 的量纲（315–30000）吃掉。
- **JAR 是次级加分 + 同分排序器**，不是主项。JAR 300 以内多是 おっ / くっ / やっぱ 这类
  词，LAM 越大它们越靠前；用户表示要学这些词，所以默认不挡。
- **默认不做词性过滤**。`--drop-phrases` 才会挡 Anki 标为惯用句/词缀/代词的词
  （会连带挡掉 おっ / にゃあ）。

取词：**按分数降序取前 N**；候选不足 N 时有几个取几个，不硬凑。

## 三之二、两道词义闸（2026-10-29 加）

选出来的词还必须在**意思上**和字幕对得上，否则今天学的就是错的义项。两道闸一前一后：

**闸 1 · 读音（机械，免费）** —— 同一个词形下可能挂着读音不同的卡：

> `頭` 名下有两张卡：`あたま`（头）和 `かしら`（首领，家长）。
> 字幕说 `あたま` 时只能标前者，不能把「首领」那张一起标上。

判据：卡片 `Transliteration` / `VocabFurigana` 拆成读音集合（`から,そら` 这种多读音
要拆开、`(オ) bier,びーる` 要去括号英文），和字幕里该词的**词典形读音**取交集；
交集为空 → 这张笔记不打 tag。卡片没写读音 / 只有英文 → 放行（判不了不误杀）。

**闸 2 · 义项（语义，调本地模型）** —— 词形和读音都对，意思仍可能不同：

| 词 | 卡片释义 | 字幕句 | 实际义项 |
|---|---|---|---|
| 空 | 空的 | 同じ**空**の下に | 天空 |
| 吐く | 呕吐 | すぐ**吐く**んじゃなく吸って | 呼气 |
| 参る | 去；来；参拜 | いやいや **まいった**ね | 糟了、认输 |
| 実 | 果实 | **実は**これ | 其实 |

判据：`sense_gate.py` 把「字幕句 + 目标词 + JMdict 义项表 + 卡片中文释义」交给本地模型，
判出义项编号并回答卡片释义是否对得上。**只有模型明确判 False 才剔**；词典查不到、
模型判不了一律放行。被剔的词用后面的候选补位，并写进报告「义项核验被剔除」一节。

- 默认开；`--no-sense-check` 跳过（离线/快速跑）。
- 结论缓存 `data/daily_new/sense_cache.json`，同一句同一个词不重复判。
- 判不出来的词不丢，只有 `card_ok=false` 才拦。

## 四、输出怎么读

| 输出行 | 含义 | 正常值 |
|---|---|---|
| `窗口：N 集（同目录整部作品）` | 这次实际扫了几集 | 与作品集数一致 |
| `候选：C 个词（JAR 1–30000、有未学笔记）` | 命中多少可学的词 | 越多越好，0 说明全学完或输入没命中 |
| `排除：JAR 超范围 x / 没有未学笔记 y` | 被硬门槛挡掉的词 | 两个数都正常存在 |
| `公式：S = ln(1+次数) + …` | 本次实际用的权重 | 与 `--mu` / `--lam` 一致 |
| `分布：出现≥5 a / 跨集≥3 b / JAR≤4000 c` | 候选的粗粒度画像 | 三项越大越容易凑满 30 |
| `入选：30 个词 / 35 张笔记` | 名额按词、标签按笔记 | 笔记数 ≥ 词数 |
| `分数：入选最高 3.53 / 最低 2.85；第 31 名 …` | 第 30 名和第 31 名的分差 | 分差很小说明边界词可替换 |
| `旧标签：X 个；保留 K；摘除 R；新增 A` | 全量替换的差集 | 最终 = K + A |
| `现场复核剔除` | 两次读取之间被学过的卡 | 一般 0 |
| `回读校验通过` | 写后重查标签集合 = 入选集合 | 必须是「通过」 |
| `没有可选的词：本次不改库…` | 候选 0，旧标签保留 | 检查输入或是否已学完 |

产物（commit 后写）：

- `output/daily/today_new_words.md` —— 给人看的稳定路径报告（每次 commit 覆盖）
- `data/daily_new/<日期>/picked.json` —— 机器可读：词 / 分数 / 分数拆解 / 次数 / 集数 / noteId
  列表（`picked[]` 的顺序就是每日讲义的排序：分数降序）
- `data/daily_new/state.json` —— 回退记录（运行前 / 运行后 noteId）

## 五、机械规则（脚本已做，别在提示词里重算）

- **排序键**：分数降序 → 词形（同分稳定）。
- **分数的 JAR 项被夹在 1–30000**：`JAR=0`、`JAR>30000`、无排名都不会算出负分或爆分。
- **词的排名**取该词所有笔记里的最小值；无排名（999999）在 JAR 门槛处被排除。
- **「学过」按笔记**：该笔记所有卡 `type != 0` 才算学过；`queue == -1` 算挂起；
  埋藏（`queue == -3`）仍可选（打 tag 不解除埋藏）。
- **写前差集**：只摘 `旧 - 新`、只加 `新 - 旧`，交集不动（幂等，避免反复改 `mod`）。
- **上限**：入选词数 ≤ N；写后 `find_notes('tag:"今天学习生词"')` 回读校验。
- **回退记录**：commit 前先写 `state.json` 的 `before`，再动库。
- 打完标签后 Anki 浏览器要**切走再切回或 F5** 才刷新。

## 六、失败处理

| 现象 | 动作 |
|---|---|
| `AnkiConnect 不可用 … 请先启动 Anki` | 让用户打开 Anki，重跑（脚本幂等） |
| `牌组不存在或没有子牌组：0-日本语学习::0-词汇::…` | `jp_decks.py` 与库里牌组名对不上。**问用户**改哪边，不要自己猜 |
| `没有找到字幕文件：…` | 路径写错 / 目录里没有字幕；确认文件与编码后重跑 |
| `没有从字幕里解析出任何台词：…` | 字幕格式不认识；确认文件后重跑 |
| `没有可选的词：本次不改库` | 这段材料里没有「已有且未学」的词。别 commit，先问用户是否换输入或确实要 `--clear` |
| 入选不足 30 / 候选很少 | 正常（材料太短或都学过了）。**不要**去调 `--mu` / `--lam` 凑满 30，先报给用户 |
| `回读校验失败：缺失/多出 …` | 退出码 1。先 `--revert --commit` 恢复，再把缺失/多出的 noteId 报给用户 |
| `找不到回退记录 …state.json` | 还没用本工具 commit 过；不要手工摘 tag，先确认来源 |
| 名单里出现人名/语气词/基础词 | 现有过滤只挡人名/惯用句/词缀；仍混进来就**先给用户看**，不要自己改规则或 `--commit` |

**不要**为了绕过上述问题去 `sqlite3` 直连库、改 `jp_decks.py`、或手工在 Anki 里批量加 tag——
工作区只走 `code/common/anki_api.py`。

## 七、收工汇报（给用户）

1. 输入是什么（目录 / 单集 / 粘贴文字）、`--n` 是多少、用的什么 `--mu` / `--lam`、有没有 `--commit`；
2. 窗口几集、候选多少、分布（出现≥5 / 跨集≥3 / JAR≤4000）、入选几词几笔记；
3. 今天的词表（按分数降序，带读音、JAR、次数/集数、分数、首句）；
4. 分数边界：第 30 名和第 31 名差多少（差得小就说明这批词可替换）；
5. 标签变化：旧标签几个、保留几个、摘除几个、新增几个，回读校验是否通过；
6. 回退命令：`python code\tools\today_new_words.py --revert --commit`；清空 `--clear --commit`。

## 八、与其它技能的边界

- 要把这 N 个词排到新卡队首（改 `due`）→ `jp-anki-activate`；本技能**不排期**。
- 字幕/文字的复习标签 `复习::*` → `jp-anki-subtitle-tag`；两者标签不同、可并存。
- 文字里出现、但 Anki 里没有的词 → 不在本技能范围（本技能只挑「已有且未学」）；
  JAR >30000 的词也**不建新卡**，只排除。挖词建卡 → `jp-anki-mine`。
- 每日讲义 → `jp-anki-daily-lesson`；弱项分析 → `jp-anki-daily-weak`；`JitenAnimeRank` 回填 → `jp-anki-jiten-rank`。
- 本技能**只加/摘一个标签**，别的阶段要动卡请加载对应技能。
