# 报告样板（sample）

> 状态：active ｜ 最后核实：2026-10-30

这里放的是**作者本人收藏跑出来的真实报告**，用来回答「这个工作区最后会产出什么样的文件」。
不是演示数据、也不是截图：打开就是完整的一份 Markdown，含表格、统计和结论，可以直接看格式与口径。

| 样板 | 是什么 | 生成入口 |
|---|---|---|
| [每日讲义.md](每日讲义.md) | 早上学词前看的讲义：读音、词性、义项、例句与讲解（样例为 2026-10-30，36 个词） | `cli.py daily stats` → `plan` → `check` → `gen` |
| [字幕覆盖率与词汇量报告.md](字幕覆盖率与词汇量报告.md) | 96 集字幕的整体水位：覆盖率、句子可懂度、词汇量三个分母、新词表 | `python code\analysis\vocab_cover\report_build.py` |
| [单集生词报告.md](单集生词报告.md) | 一部作品 / 一集的生词报告：规模、分档、题材通用词、值得挖 / 不用记 | `cli.py vocab report <目录>` |
| [挖掘窗口分析.md](挖掘窗口分析.md) | 「每季只挖前 N 集值不值」：覆盖占比、效率、边际效率、窗口外高价值词 | `cli.py vocab mine_window --k 3` |
| [词汇三卡组配比.md](词汇三卡组配比.md) | 三个词汇牌组的配比、已学 / 成熟、每天放几张的建议 | `python code\analysis\vocab_deck_ratio.py` |
| [ankiR-学习分析.md](ankiR-学习分析.md) | 留存、健康分、复习负荷与未来预测（R 包 ankiR，只读） | `cli.py r summary` / `r due` 后整理 |
| [弱词清单.md](弱词清单.md) | 近几天答错 / 判「困难」的词，按错误次数分组 | `cli.py weak build-list` |

说明：

- 数字来自作者**当时**的收藏与字幕（2026-09 / 10），会随时间变化。看格式与口径，别把具体数值当基准。
- 本机绝对路径已替换为 `<工作区根>`、`<python>` 等占位符，用户名已脱敏；其余内容保持原样。
- 日期化的跑批记录、一次次实验的复盘等**不进**这里，仍只在本地 `docs/reports/` 保留；
  这里只放「日常会重复产出」的几类报告。
