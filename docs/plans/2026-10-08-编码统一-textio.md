# 编码统一（`code/common/textio.py`）—— 结论

> 状态：active ｜ 最后核实：2026-11-09
>
> （重构已于 2026-10-08 落地并验收，本文件已压缩为结论）

## 背景

本机代码页 936（GBK）：管道/重定向下 Python stdio 按 GBK 编码，日文要么
`UnicodeEncodeError` 要么静默乱码；PS 5.1 `Get-Content` 默认 ANSI 读 UTF-8 JSON。
2026-10-08 事故：`Get-Content | ConvertFrom-Json` 解码崩 → `$null` → 「字段为空就删」
判断恒真 → `output/cmp4` 的 39 个产出被误删。当时全仓手写编码补丁 52 处 / 45 个文件。

## 最终落地结果

- 新增 `code/common/textio.py`：import 即把 stdio 钉成 UTF-8；`read_text/load_json/run`
  容错解码（非 UTF-8 在 stderr 出声）。现在全仓 100+ 个脚本 `import textio`（AGENTS.md 铁律 2）。
- 手工编码补丁（R1）与缺 import（R2）全部归零；改动 115 个文件，`py_compile` 129/129 通过。
- `textio.py audit --strict` 五条规则（R1/R2 致命）长期保持全 0，已收进 `doctor` 第 3 项。
- PowerShell 侧配套 `code/common/ps-utf8.ps1`（必须 UTF-8 带 BOM；DSH 受限令牌下只能
  `iex ([IO.File]::ReadAllText(...))` 读入执行）。
