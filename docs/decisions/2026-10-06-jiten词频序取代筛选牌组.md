# ADR：用 Jiten 动漫词频序决定新卡顺序，取代筛选牌组

> 状态：active ｜ 最后核实：2026-10-10 ｜ 日期：2026-10-06

## 背景

学词汇的目标是「按动画里出现的普遍频率从高到低学」，而不是按卡组/级别/导入顺序。
当时代用**筛选牌组**「素材优先」造一条独立的新卡队列（搜索 `is:new tag:素材优先`，
`order = DUE`），各大牌组 `new/day = 0` 只做复习。

问题：筛选牌组只是**另一条队列**，与主卡组的顺序是两套东西；而且它按 `cards.due` 排，
`due` 从哪来又取决于谁先跑了什么脚本 —— 每集激活会把当集卡片压到队首，
存量队列被逐集往后挤，「全局词频序」实际上不成立。

## 决定

1. 删除筛选牌组，清零 `素材优先` 标签（清单留在 `data/vocab_cover/pool_tag_removed.json`）。
2. 用 **Jiten Anime 词表**（[jiten.moe](https://jiten.moe/frequency-dictionaries)，建在 3,762 部
   动画字幕上，CC BY-SA 4.0）给**所有** live 新卡排序，把顺序写成 `cards.due`
   （= 位置），实现见 `code/analysis/vocab_cover/freq_external.py` +
   `make_activate_plan.py` + `activate.py apply --global`（一条命令：
   `python code/cli.py vocab reorder-jiten`）。
3. 卡组选项改为 `gather order = Ascending position`（`newGatherPriority = 1`），
   该枚举**不分卡组**，于是卡组自己就按全局词频发卡。

## 理由

- 本地字幕语料只有 36 集 / 8.2 小时：最高频词 196 次，第 50 名往后掉到个位数，
  排名基本是噪声，还被打单部作品污染。Jiten 的深度好得多，且按「出现在多少部作品里」排，
  天然抵消单集噪声。
- 最硬的理由：11,990 张 live 新卡里只有 **1,949** 个词在本地 36 集里出现过 ——
  本地清单对绝大多数卡**排不了先后**；Jiten 能给其中 96.0% 排上名。
- 只有**一个**顺序来源（`cards.due`）时，才有「全局有序」可言；
  两套队列（筛选牌组 + 主卡组）永远对不齐。

## 影响

- 新卡顺序由位置决定 → 任何 `addNotes`（如 `mine.py write`）拿到的都是**随机位置**，
  会插进排好的队列中间；加词后要重排（`vocab reorder-jiten --commit`，或浏览器按
  Sort Field 列排序 → Reposition）。这是**已知漂移**，不是 bug。
- 每集激活仍然照旧（不带 `--global` 跑 `activate.py`，把当集卡压到队首）——
  先跑全局重排，再跑当集，顺序就是「先跑哪个」。
- 「牌组树顺序」不再有意义；依赖子 deck 名的脚本改读笔记标签。

## 何时该重新考虑

- 若改用「按领域/题材分层学」而不是「按通用频率」，全局单序就不再合适。
- 若 Jiten 词表许可或可用性变化（`docs/reports/外部词表排序对比.md`——本地报告，未入库——
  记录了口径与对比）。
