**这是什么**：单词例句的教学口径（新句 + 振假名 + 合并讲解），也是模型提示词的来源。
**为什么存在**：补例句②与讲义共用同一套教学口径，写在一处才有一致性。
**什么时候读**：改 `core6000_example_prompt.md` / `lesson_local_prompt.md` 之前。

# 目标

用户会提供：
- 一个日语单词
- 读音、词性、释义
- 一个原例句
- 原例句已有的教学解释

你需要输出 3 项：
1. 新例句
2. 新例句标注 ruby
3. 合并教学：把原例句和新例句放在同一份解释里，不要拆成两份

# 输入格式

用户可能这样给：

```text
单词：徹夜
读音：てつや
词性：名词/サ変動词
释义：熬夜 / 通宵

原例句：ゆうべは徹夜しました。

已有解释：
中文翻译：昨晚熬夜了。
核心词汇：徹夜（名词/サ変動词）：熬夜，彻夜未眠。
语法要点：
1. 助词「は」：提示主题，强调时间点「ゆうべ」。
2. 礼貌过去式「～しました」：由动词「する」变形而来，表示动作在过去已经完成，且语气礼貌。
动词变形解析：
原形：する
变形步骤：する → します → しました
语境与表达风格：
该句采用了礼貌体（です・ます体），语气平实且得体。常用于日常口语、职场对话或向他人报告个人状态的场景。
```

# 输出格式

必须严格输出以下 3 项：

## 1. 新例句

只写一句新的日语例句。要求：
- 短
- 自然
- 必须使用目标词
- 语境、内容、语气或句型要和原例句不同
- 不要只是换主语、换时间、换地点
- 优先日常口语中能用的句子

## 2. 新例句标注 ruby

给新例句中所有汉字标注 ruby。
格式：
`<ruby>漢字<rt>かな</rt></ruby>`

平假名、片假名、数字、符号不标。
读音不确定时查词典，不要硬猜。

## 3. 合并教学

把原例句和新例句合并成一份教学。
不要分成两份。
结构固定如下：

```html
<div>
<p><b>例句</b>：<br>
① 原例句（带 ruby）<br>
② 新例句（带 ruby）</p>

<p><b>中文翻译</b>：<br>
① 原例句翻译<br>
② 新例句翻译</p>

<p><b>核心词汇</b>：<br>
目标词（词性）：释义<br>
新例句中出现的其他重要词（词性）：释义<br>
...</p>

<p><b>语法要点</b>：<br>
① 原例句语法点<br>
② 新例句语法点</p>

<p><b>动词变形解析</b>：<br>
① 原例句相关变形<br>
② 新例句相关变形；若没有动词变形，也要说明</p>

<p><b>语境与表达风格</b>：<br>
① 原例句语境、语气、使用场景<br>
② 新例句语境、语气、使用场景<br>
两句对比：说明原句和新句的语境差异</p>
</div>
```

# 核心规则

1. 保留用户已有解释，不要丢失原句信息。
2. 把新例句的解释合并进同一份教学。
3. 所有汉字都要标 ruby。
4. 原例句也要重新标 ruby，即使用户原句没标。
5. 新例句必须和原句语境不同。
6. 不要输出两个分开的教学块。
7. 中文解释要简洁、准确、适合日语学习者。
8. 若原解释缺少某些部分，可以补全。
9. 若目标词有多种读音或词性，以用户输入为准。
10. 不要编造不自然的日语用法。

## 输入

```text
单词：徹夜
读音：てつや
词性：名词/サ変動词
释义：熬夜 / 通宵

原例句：ゆうべは徹夜しました。

已有解释：
中文翻译：昨晚熬夜了。
核心词汇：徹夜（名词/サ変動词）：熬夜，彻夜未眠。

1. 助词「は」：提示主题，强调时间点「ゆうべ」。
2. 礼貌过去式「～しました」：由动词「する」变形而来，表示动作在过去已经完成，且语气礼貌。
```

## 输出

### 1. 新例句

徹夜は体に悪いよ。

### 2. 新例句标注 ruby

<ruby>徹夜<rt>てつや</rt></ruby>は<ruby>体<rt>からだ</rt></ruby>に<ruby>悪<rt>わる</rt></ruby>いよ。

### 3. 合并教学

```html
<div>
<p><b>例句</b>：<br>
① ゆうべは<ruby>徹夜<rt>てつや</rt></ruby>しました。<br>
② <ruby>徹夜<rt>てつや</rt></ruby>は<ruby>体<rt>からだ</rt></ruby>に<ruby>悪<rt>わる</rt></ruby>いよ。</p>

<p><b>中文翻译</b>：<br>
① 昨晚熬夜了。<br>
② 熬夜对身体不好哦。</p>

<p><b>核心词汇</b>：<br>
<ruby>徹夜<rt>てつや</rt></ruby>（名词/サ変動词）：熬夜，通宵。<br>
ゆうべ（名词）：昨晚。<br>
<ruby>体<rt>からだ</rt></ruby>（名词）：身体。<br>
<ruby>悪<rt>わる</rt></ruby>い（い形容词）：不好的，坏的；「体に悪い」表示“对身体不好”。<br>
よ（终助词）：用于提醒、告知或轻微强调，口语中常用。</p>

<p><b>语法要点</b>：<br>
① ゆうべは<ruby>徹夜<rt>てつや</rt></ruby>しました。<br>
・助词「は」：提示主题，强调时间点「ゆうべ」。<br>
・「～しました」：礼貌过去式，表示动作在过去已经完成。<br>
② <ruby>徹夜<rt>てつや</rt></ruby>は<ruby>体<rt>からだ</rt></ruby>に<ruby>悪<rt>わる</rt></ruby>いよ。<br>
・「徹夜は」：提示主题，把“熬夜”作为谈论对象。<br>
・「体に悪い」：固定搭配，表示“对身体不好”，「に」表示影响所及的对象。<br>
・终助词「よ」：用于告知、提醒或轻微强调，语气口语化。</p>

<p><b>动词变形解析</b>：<br>
① 徹夜する：原形 → 徹夜します（礼貌现在时）→ 徹夜しました（礼貌过去时）。<br>
② 本句没有动词变形。「徹夜」在此作名词使用；「悪い」是い形容词的现在肯定形式。若改为过去式，可用「徹夜は体に悪かった」。</p>

<p><b>语境与表达风格</b>：<br>
① 采用礼貌体（です・ます体），语气平实得体，常用于日常口语、职场对话或向他人报告个人状态。<br>
② 采用普通体口语，带提醒、关心语气，常用于朋友、家人之间劝人不要熬夜。<br>
两句对比：①是报告“昨晚熬了夜”，②是评价、提醒“熬夜对身体不好”。</p>
</div>
```
