# 专有名词收集：`0-词汇::3-专有词汇`

> 状态：active ｜ 最后核实：2026-10-22
>
> 一句话：**从字幕里收专有名词**（人名/地名/组织/概念/技能/种族/称号/作品名），
> 建成「看词形 → 回忆读音与意思」的卡片。只收集，**不进学习队列**。

---

## 1. 它是什么 / 不是什么

| | |
|---|---|
| **是什么** | 一条可复用的**原子能力**：一段文字 + 背景 → 专有名词清单；外加一层把字幕变成卡片的管线 |
| **不是什么** | 不是生词挖掘。`0-素材生词` 那边仍然**不收专名**（`jp-anki-mine` 的 `include=false` 判据不动）；覆盖率统计的 `proper` 档位也不动 |
| **不回溯** | 提取源是**字幕文件**，按集手动跑；不去扫历史例句卡 |
| **不进队列** | 脚本不写 `due`/`type`/`queue`、**不 suspend、不改牌组选项**。何时停学由你自己在 Anki 里控制 |
| **不配句子音** | 卡上的句子是模型写的**介绍句**，不是原声台词；只配单词读法音频 |

## 2. 两层结构

```
字幕 .srt ──┐
            ├─▶ proper_extract.extract()   ← 原子能力：文字 + 背景 → 专名清单（不碰 Anki）
自由文本 ───┘            │
                         ▼
                   proper.py scan   ── 合并/去重/判据 → candidates.json + report.md
                         │
                   split → gen      ── 本地模型写成卡片内容（读音/类别/意思/介绍句/讲解）
                         │
                   verify           ── 唯一校验点 → verified.json
                         │
                   write            ── 写入 3-专有词汇（默认演练）
                         │
                   audio            ── edge-TTS 读 Reading 生成 Word Audio
```

**为什么分两层**：提取口径只有一份实现，字幕、文章、小说段落都能复用；
出问题可以只拿一句话复现，不用碰整集数据。

## 3. 原子能力（单独可用）

```powershell
$PY = "python"

# 一句台词
& $PY code\tools\proper_extract.py --text "気持ちを届けるのはシルフさんたちのお仕事" `
    --background "作品=水星领航员 第01集" --json

# 一段文章 / 标准输入
& $PY code\tools\proper_extract.py --file temp\scene.txt --background "平家物语 第02集"
Get-Content temp\cue.txt | & $PY code\tools\proper_extract.py --stdin --background "…" --json

# 只看脚本预扫（不连本地模型，离线回归用）
& $PY code\tools\proper_extract.py --text "…" --no-model
```

输出：

```json
{"background":"作品=水星领航员 第01集",
 "text":"気持ちを届けるのはシルフさんたちのお仕事",
 "names":[{"word":"シルフ","categories":["种族"],"reading":"しるふ",
           "gloss":"…","why":"…","evidence":"…","source":"model"}],
 "issues":[]}
```

- `word` **必须逐字出现在原文里**（机械闸门）；碎片可以被**前后补全**成完整专名
  （`大納` → `大納言`），只要补全后仍在原文里。
- `categories` 可多个（`メリオダス` 是人名也是称号；`七つの大罪` 是作品名也是组织）。
- `reading` 一律转成**平假名**；不是纯假名就清空。
- 召回是两层：Sudachi `固有名詞` + 片假名长串只当**提示**，判定主力是本地模型。
  实测 `メリオダス`/`ゴウセル`/`キング`/`シルフ` 都会被 Sudachi 判成普通名词 —— 靠模型层捞回来。

## 4. 每集收集

```powershell
$EXE = "code\execution"

& $PY code\cli.py doctor                       # 强制门禁
& $PY $EXE\proper.py model --check              # 笔记类型就绪？
& $PY $EXE\proper.py model --commit             # 缺了就建（幂等；已存在只校验不覆盖）

& $PY $EXE\proper.py scan "subtitles\ARIA The ANIMATION\Aria The Animation 04.jp.srt" `
     --work 水星领航员
& $PY $EXE\proper.py split --batches 4
& $PY $EXE\proper.py gen
& $PY $EXE\proper.py verify
& $PY $EXE\proper.py write                      # 演练
& $PY $EXE\proper.py write --commit
& $PY $EXE\proper.py audio --commit             # 读法音频（单独一步）
```

常用参数：

| 参数 | 作用 |
|---|---|
| `--work <作品>` | 出处（必填）。要与库里 `动画::<作品>` 的作品段一致；对不上时 report 会列出现有标签 |
| `--window N` | 一次送模型几条台词（默认 6；集数多时 8 更快） |
| `--per-request N` | 一次请求几段文字（默认 8；本地模型慢就调小） |
| `--limit N` | 每集只处理前 N 条台词（冒烟用） |
| `--include-known` | 已在 `core6000`/`考级词汇`/**`素材生词`** 里的也收（`シングル`/`プリマ` 这类称号常需要它） |
| `--run <目录名>` | 操作某一次历史 run（默认最新） |

产物目录：`data/vocab/proper/<作品>_<集>/`

```
candidates.json     候选（词形/类别提示/次数/首例句）
report.md           人看：按类别分布、明细、被词表拦下的「可强收」清单、问题
gen/input_NN.json   切批后的输入
gen/output_NN.json  本地模型写的卡片内容
gen/failed.json     没判出来的（gen --fix-failed 重跑）
gen/verified.json   唯一校验后的待写载荷
```

## 5. 手动补一张

不在当前字幕里的专名（例：亚瑟王传说中的 `メリオダス`）：

```powershell
& $PY $EXE\proper.py add --word メリオダス --reading めりおだす `
    --source 亚瑟王传说 --text "アーサー王伝説の騎士メリオダス。" --commit
```

`--source` 是**出处标签**。同名词不同出处 = 两张卡（`メリオダス` + `七大罪` / `メリオダス` + `亚瑟王传说`），
重复跑报「已存在」。`--text` 省略时用 `--word` 本身当例句。

## 6. 卡片

笔记类型 **`Japanese Proper Noun`**（1 个模板 `Word -> Meaning`）：

```
正面                          背面
┌──────────────┐        ┌─────────────────────────────┐
│  メリオダス   │   →    │ メリオダス（小）              │
│  （48px 居中）│        │ めりおだす  ▶ Word Audio     │
└──────────────┘        │ [人名・称号] 梅利奥达斯…      │
                        │ ──────────────────────      │
                        │ 日语介绍句（带振假名）        │
                        │ 介绍句中文翻译                │
                        │ ──────────────────────      │
                        │ AINote：词条 / 出处与背景     │
                        │ Source（出处｜原句）14px 灰   │
                        └─────────────────────────────┘
```

| 字段 | 说明 |
|---|---|
| `Index` | 全局唯一序号（**首字段 = Anki 的查重字段**，所以同名两卡能共存） |
| `Word` | 专名本体 |
| `Reading` | 平假名读音（纯假名；TTS 与卡面都用它） |
| `Meaning` | 一句话中文意思 |
| `Categories` | 卡面显示的类别（`人名 / 称号`） |
| `Intro` | 日语介绍句，`ruby` 由 `ruby_engine` 确定性渲染 |
| `Intro Translation` | 介绍句中文翻译 |
| `AINote` | 中文讲解两段：`词条` / `出处与背景` |
| `Source` | `出自「作品」第NN集｜原句：…` |
| `Word Audio` | `proper-<词>-<hash>.mp3`，edge-TTS `ja-JP-NanamiNeural` 读 `Reading` |

**正面只有 `Word`**：读音、类别、音频都在背面，否则「回忆读法」被剧透。

### 标签（类别扁平；出处继承动画作品标签）

```
专有名词                         必有
人名 / 地名 / 组织 / 概念 / 技能 / 种族 / 称号 / 作品名 / 其他   1..n（扁平）
动画::水星领航员                 出处：继承库里现有的动画作品标签（两层，不带季度/集数）
```

- **出处标签继承 `动画::<作品>`**：例句卡是 `动画::水星领航员::第一季::第04集`，
  专名卡只挂 `动画::水星领航员` —— 于是 `tag:动画::水星领航员` 同时搜到两种卡
  （实测 231 = 188 例句 + 43 专名）。**不带季度/集数那两层。**
  非动画出处（`亚瑟王传说`）就是一条裸标签；`--source "动画::七大罪"` 也可以显式指定。
- **类别标签一律扁平**：一个专名可能同时是「人名」和「称号」，多个平级标签才是正确表达。
- **不写批次/日期标签**（2026-10-22 决定：没必要）。回滚见 §8。
  **保留字**：`专有名词`、九个类别名。

「关联/原型」（`related`，例：亚瑟王传说）**不进标签**，写进 `AINote` 的「关联：」段。
实测模型会把同作品的其他角色也塞进 related（`晃`→`蓝华`、`オレンジぷらねっと`→`アリア社`），
当标签用就是噪声。

### 读音以卡面 ruby 为准

`Reading` 由 `Intro` 的振假名反推（`ruby_engine` 渲染，权威），覆盖模型给的读音。
实测模型把 `藍華` 读成 らんか、`火の番人` 读成 かんじん、`大鐘楼` 读成 だいしゅろう，
而 ruby 里是对的（あいか / ひのばんにん / だいしょうろう）。TTS 也读 `Reading`，所以这一步同时修正发音。

## 7. 怎么让它不进学习队列

脚本**不动**调度与牌组配置（这是刻意的：由你控制）。两种做法：

1. Anki → 牌组选项 → 找到该牌组的预设 → **新卡/天 = 0**（最干净，卡还是新卡）；
2. 浏览器搜 `deck:"0-日本语学习::0-词汇::3-专有词汇"` → 全选 → **挂起**。

`write` 收工时会打印该牌组**当前** `new/day`，提醒你现在的状态。

## 8. 回滚

| 范围 | 做法 |
|---|---|
| 某一部作品 | 浏览器搜 `deck:"0-日本语学习::0-词汇::3-专有词汇" tag:"动画::<作品>"` → 全选删除 |
| 某一批（同一天跑的） | 同一次查询后，按浏览器 `Added` 列排序圈出那天的卡 |
| 整个牌组 | 浏览器搜 `deck:"0-日本语学习::0-词汇::3-专有词汇"` → 全选删除 |
| 笔记类型 | `proper.py model --delete`（0 张卡引用时才允许） |
| 代码 | 删 `proper_extract.py` / `proper.py` / `check_proper.py` 与 `DECK_PROPER` 常量 |

没有批次标签（这是刻意的，见 §6）：要「按批」就用 `Added` 列，要「按作品」就用出处标签。

**重跑是安全的**：`write` 写库那一刻会再查一遍「目标牌组里有没有同 `(词形, 出处)`」，
已存在就跳过（实测第二次跑报「已存在、跳过 43 张」）；`audio` 也跳过已有音频。

## 9. 与其它脚本的关系

| 链路 | 会不会带上新牌组 |
|---|---|
| 每日讲义 `today_new.py` | **不会**：`STUDY_UNITS` 里没有它，字段名也不同 |
| 覆盖率 `collect_vocab.py` | **不会**：`DECK_SPECS` 未登记 → 整牌跳过（专名本来就不算词汇量） |
| `jiten_reorder` 插件 | **不会**：`config.json` 的 `decks` 只有 `0-素材生词` |
| `activate.py` | **不会**：只索引考级词汇 / core6000 / 两个标签类 |
| 生词挖掘 `mine.py` | 互不影响：那边判据是「不在词汇牌组」，专名卡故意不收进生词牌组 |

## 10. 已知边界

- **不印句子音频**：介绍句没有原声；要句子音得另开任务。
- **介绍句是模型写的**：卡片保留 `Source` 原句可追溯；`verify` 抽检 + `report.md` 复核。
- **Sudachi 会把角色名判成普通名词**（`メリオダス` 等），所以预扫只当提示，判定的主力是模型层。
- **`Reading` 是平假名**（`メリオダス` → `めりおだす`）：卡面显示「怎么读」，TTS 也读它。
- 同一作品内同名不同角色属罕见，先按一张收，遇到再人工拆。
